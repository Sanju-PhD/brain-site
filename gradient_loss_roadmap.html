VoxelMorph Custom Loss Smoothness Penalty

This is the one. Implements a custom 2D VoxelMorph loss with two components — reconstruction loss and a smoothness penalty — and includes the actual gradient function in code.

You can read the loss function directly and run it. This is your starting point for implementation.

03
Literature · Closest to Your Objective
"Multi-modal unsupervised brain image registration using edge maps"
arxiv.org/pdf/2202.04647
Gradient Magnitude Edge Maps Geometry Constraints

Proposes using gradient magnitude of the image — the edges — as auxiliary information during training. The intuition: locations with strong gradients represent tissue transitions and act as geometry constraints.

This is almost exactly your objective. Read the loss function section using your reading system.
