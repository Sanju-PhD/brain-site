Spatial Pre-processing

Spatial processing: It has major two types: 1. Intensity transformations 2. Spatial filtering

What is spatial domain pre-processing? and how is it differ from transform domain pre-processing?

The processing occurs on a spatial domain means area or a plane containing pixels.

What is Intensity transformation?

g(x,y) = T[f(x,y)]

where T is the transformation function, an operator being aplied on the pixels of the image, f is the input image, and g is the output image. Intensity here is nothing but the gray level or a mapping function.

s=T(r)

When we define a point from where contrast going from dark to bright or bright to dark, that point is called as a threshold point.

8 bit image has 256 entries.

1. Linear transformation

It is a linear mapping from input to output. It is a straight line function. It has a intensity level range [0, L-1] where L is the number of possible intensity values in the image. For an 8 bit image, L is 256, so the range is [0, 255].

s = L-1-r
Using this equation, we can get the negative of an image. If its black, it becomes white and if its white, it becomes black. So, the contrast is reversed.

2. Lograthmic transformation

It is a non-linear mapping from input to output. It is a curve function.

s = c log(1+r)
Log function compresses the dynamic range of the input image. It is used to enhance the details in the dark regions of an image while compressing the bright regions. The constant c is a scaling factor that can be adjusted to control the degree of enhancement.

3. Power-law transformation

It is also a non-linear mapping from input to output. It is a curve function.

s = c r^γ
Power-law transformation, also known as gamma correction, is used to adjust the brightness and contrast of an image. The parameter γ (gamma) controls the shape of the transformation curve. If γ < 1, the transformation will brighten the image; if γ > 1, it will darken the image. The constant c is a scaling factor that can be adjusted to control the overall intensity of the output image.

Template

Templates are the spatial probability maps, means they tells us that hippocampus is probably in this region of MNI space. So, it is a prior knowledge about the location of the structure in the brain. It is used to guide the registration process and improve the accuracy of the alignment.

Template doesn't teach model to see, it tells model where to look.

What does registration do?

Registration minimizes that distance by estimating a transformation field. It has two types: 1. Linear registration: It is a global transformation that includes translation, rotation, scaling, and shearing. It is used to align images that are similar in shape and size. 2. Non-linear registration:It aligns local anatomy by deforming every voxel.
